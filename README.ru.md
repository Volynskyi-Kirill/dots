# Dots Game (Игра "Точки")

Браузерная многопользовательская стратегическая игра "Точки" с классическими правилами, современным минималистичным дизайном и отзывчивым управлением.

## 🌟 Особенности

- **Полный мультиплеер:** Реал-тайм игра через WebSocket.
- **Классические правила:** Захват территории с использованием алгоритма Flood-Fill (поиск в ширину).
- **Адаптивный Canvas:** Поддержка Multi-touch жестов (pinch-to-zoom и drag) на мобильных устройствах, и фиксированная сетка на ПК.
- **Современный UI/UX:** Создан с использованием Next.js (App Router), Tailwind CSS v4 и shadcn/ui. Полная локализация через `next-intl`.
- **Чистая архитектура:** Игровая логика на Go полностью изолирована от слоя вебсокетов и фронтенда.

## 🛠 Стек технологий

- **Backend:** Go (Golang), `gorilla/websocket`, кастомные BFS алгоритмы.
- **Frontend:** Next.js (React 19), TypeScript, Tailwind CSS, shadcn/ui, HTML5 Canvas.
- **Инфраструктура:** Docker Compose.

## 🚀 Как запустить локально

Для запуска проекта вам понадобятся только установленные **Docker** и **Docker Compose**.

1. Клонируйте репозиторий.
2. В корне проекта выполните команду:
   ```bash
   make up
   ```
3. Откройте приложение в браузере:
   - Игра доступна по адресу: [http://localhost:3000](http://localhost:3000)

### Полезные команды (Makefile)

- `make up` — поднять все контейнеры в фоне
- `make down` — остановить и удалить контейнеры
- `make rebuild-tochky` — пересобрать фронтенд-контейнер Next.js
- `make logs` — смотреть логи фронтенда и бэкенда в реальном времени
- `make test` — запустить unit-тесты алгоритма игровой логики (Go)
