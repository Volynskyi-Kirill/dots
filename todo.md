# Режим наблюдателя (Spectator Mode) — План внедрения

## 🎯 Цель
Позволить третьему и последующим пользователям, перешедшим по ссылке в комнату, подключаться к игре в качестве **наблюдателей (Spectators)** без возможности совершать ходы, но с просмотром игрового процесса в реальном времени.

---

## 🛠 Необходимые изменения

### 1. Бэкенд (Go)

- [ ] **[`backend/internal/service/room_manager.go`](backend/internal/service/room_manager.go)**
  - Убрать жесткое ограничение `if len(room.Clients) >= 2 { return nil, 0, nil }`.
  - Реализовать распределение ролей:
    - Первые два свободных слота занимают **Игрок 1** (`1`) и **Игрок 2** (`2`).
    - Третий и последующие клиенты получают статус наблюдателя (`playerID = 0` / роль `Spectator`).
  - Добавить методы/счетчики для отслеживания количества активных игроков и зрителей в комнате.

- [ ] **[`backend/internal/domain/models.go`](backend/internal/domain/models.go)**
  - Расширить модель состояния/сообщений WebSocket, добавив информацию о назначенной роли игрока (`role: "player1" | "player2" | "spectator"` или `yourPlayerId: int`) и количестве зрителей (`spectatorsCount: int`).

- [ ] **[`backend/internal/handler/websocket.go`](backend/internal/handler/websocket.go)**
  - При подключении клиента регистрировать его в комнате и отправлять персональное приветственное сообщение с его ролью/ID.
  - В обработчике `constants.MessageMove` добавить валидацию:
    - Запретить совершать ходы наблюдателям (`if playerID == 0`). При попытке хода возвращать ошибку.
  - Рассылать всем в комнате обновленное количество зрителей при подключении/отключении наблюдателей.

---

## 2. Фронтенд (React / TypeScript)

- [ ] **[`frontend/src/types/game.ts`](frontend/src/types/game.ts)**
  - Обновить интерфейсы `GameState` и сообщений WebSocket, добавив поля:
    - `myRole: 'player1' | 'player2' | 'spectator'` (или `myPlayerId: number`)
    - `spectatorsCount?: number`

- [ ] **[`frontend/src/components/GameBoard.tsx`](frontend/src/components/GameBoard.tsx)**
  - Заблокировать взаимодействие с игровой сеткой для наблюдателей (отключить hover-эффекты и обработчик кликов `onCellClick`).
  - Добавить визуальное отображение курсора (`cursor-default` вместо `cursor-pointer`).

- [ ] **[`frontend/src/App.tsx`](frontend/src/App.tsx)**
  - Добавить бейдж/индикатор роли: **«👁 Режим наблюдения»** (Spectator Mode).
  - Отображать счетчик зрителей в комнате (например: *«👁 3 зрителя»*).
  - Адаптировать информационные сообщения о ходе игры:
    - Вместо *"Ваш ход"* / *"Ход соперника"* для зрителей показывать *"Ход Синих (Игрок 1)"* / *"Ход Красных (Игрок 2)"*.

## 📋 Чеклист проверки (Testing)

- [ ] Игрок 1 создает комнату и подключается как Игрок 1 (Синие).
- [ ] Игрок 2 переходит по ссылке и подключается как Игрок 2 (Красные). Игра переходит в статус `playing`.
- [ ] Игрок 3 переходит по ссылке:
  - Успешно подключается к комнате.
  - Видит актуальное состояние доски и все последующие ходы обоих игроков в реальном времени.
  - Не может ставить точки на доску.
  - Видит плашку «Режим наблюдения».
- [ ] Игрок 4+ также подключаются как наблюдатели.
- [ ] Счетчик зрителей корректно обновляется при входе/выходе пользователей.
